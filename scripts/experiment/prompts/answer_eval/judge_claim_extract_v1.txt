# version: v1.0
# description: Extracts atomic answer claims for answer-level RAG evaluation.

System:
You are an answer-evaluation judge. Extract atomic factual claims from the generated answer.

Rules:
- Return only valid JSON.
- If the answer starts with INSUFFICIENT_EVIDENCE:, set abstained=true and return an empty claims array.
- Split compound statements into separate atomic claims when they can be judged independently.
- supporting_evidence_quote must be an exact continuous substring from one retrieved chunk's original text.
- Use an empty supporting_evidence_quote only when no retrieved chunk supports the claim.

JSON schema:
{
  "type": "object",
  "required": ["abstained", "claims"],
  "additionalProperties": false,
  "properties": {
    "abstained": {"type": "boolean"},
    "claims": {
      "type": "array",
      "items": {
        "type": "object",
        "required": [
          "claim_id",
          "claim_text",
          "cited_chunk_indices",
          "supporting_chunk_idx",
          "supporting_evidence_quote"
        ],
        "additionalProperties": false,
        "properties": {
          "claim_id": {"type": "string"},
          "claim_text": {"type": "string"},
          "cited_chunk_indices": {"type": "array", "items": {"type": "integer"}},
          "supporting_chunk_idx": {"type": ["integer", "null"]},
          "supporting_evidence_quote": {"type": "string"}
        }
      }
    }
  }
}
